# Programação Criativa 2026

Neste repositório, você encontrará o material de apoio às aulas do curso de Programação Criativa ministrado na UFRJ em 2026.

## Acesso via web

Ao acessar https://esperanc.github.io/CreativeCoding2026 você será redirecionado automaticamente ao visualizador de slides em formato slideDown. Escolha o conjunto de slides que deseja ver.

Ao acessar https://esperanc.github.io/CreativeCoding2026/sketches, você será redirecionado ao visualizador dos sketches em p5.js(https://www.p5js.org/) usados nos slides e alguns outros demos da minha coleção de sketches.
