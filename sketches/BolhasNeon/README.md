Um sketch feito pelo ChatGPT e analisado/modificado levemente por mim, de bolhas de sabão neon.

Autor: Ysabelle Estevão de Oliveira

Prompt usado: Crie um sketch estático em p5.js. Apresente o  resultado sob a forma de um único script em javascript a ser colado num  ambiente de desenvolvimento como o editor.p5js.org. O programa  fonte deve ser documentado para ser explicado para uma plateia de  iniciantes em programação de computadores. Pode usar qualquer uma das primitivas. Se assegure que o sketch não gera sempre a mesma imagem e nem use um tamanho fixo, mas se adeque ao tamanho da janela disponível. Use windowWidth/windowHeight para criar o canvas. Gostaria que o código gera-se um bolhas de sabão que mudassem de posição e tamanho a cada execução, elas não podem ficar umas em cimas das outras e tenham cores neons diferentes entre si.
