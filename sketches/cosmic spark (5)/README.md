## Descrição
Este sketch explora o conceito de emergência por meio de uma simulação de fogo. O fogo é formado por pequenas células que seguem regras simples de propagação, intensidade e desaparecimento. A interação entre essas células gera espontaneamente diferentes formas de chama, enquanto partículas de fumaça e faíscas são influenciadas pelo vento.
