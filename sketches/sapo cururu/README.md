# Sapo Cururu

Um sapo vive numa lagoa de vitória-régias. Você decide para onde ele pula e quais moscas ele come.

## Como usar

- **Clique numa folha** para o sapo pular até ela. Cliques seguidos formam uma fila de pulos.
- **Clique numa mosca** que esteja perto do sapo para ele pegá-la com a língua.
- **Arraste** para girar a câmera e **role** para aproximar.
