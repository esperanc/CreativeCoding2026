Uma composição interativa desenvolvida em p5.js 2D para testar a junção de formas.

O projeto apresenta um círculo arcano composto por oito runas numeradas, que podem ser conectadas em diferentes sequências para realizar feitiços. Ao todo, existem dez magias, cada uma com combinações próprias e efeitos visuais distintos, incluindo chamas, escudos, relâmpagos, portais, cristais de gelo e manifestações de energia arcana.

Ao lado do círculo, um grimório interativo permite acompanhar as magias descobertas, consultar informações e revelar pistas progressivas para decifrar cada ritual. O objetivo é descobrir as nove magias iniciais para desbloquear um décimo selo secreto, acompanhado de uma animação especial de revelação.

O cenário representa uma câmara ritualística medieval, com piso de pedra texturizado, rachaduras, inscrições arcanas e velas animadas. A composição utiliza geometria procedural, sistemas de partículas, iluminação simulada, anéis rotativos e animações contínuas, criando uma atmosfera mágica e misteriosa.

### Planejamento para as próximas semanas

Nas próximas etapas do desenvolvimento, pretendo expandir tanto a apresentação visual quanto as mecânicas de interação, tornando o grimório uma experiência mais completa de descoberta e experimentação mágica.

1. Aprimoramento dos efeitos de conjuração

Desenvolver animações mais complexas e individualizadas para cada magia, com transições mais suaves, maior variedade de partículas e efeitos que representem melhor os elementos de cada feitiço.

2. Expansão do grimório

Adicionar descrições narrativas, informações sobre a origem das magias e ilustrações dos selos descobertos, tornando o grimório mais próximo de um verdadeiro livro de feitiços de fantasia.

3. Sistema de progressão e persistência

Implementar um sistema de salvamento local para preservar as magias descobertas e as pistas reveladas, permitindo continuar o progresso mesmo após fechar a página.

4. Ambientação sonora

Explorar a inclusão de efeitos sonoros para a seleção de runas, conjuração de magias e descoberta de novos selos, além de uma ambientação discreta para a câmara ritualística.

5. Refinamento da interface e responsividade

Melhorar a organização dos elementos em diferentes resoluções de tela, especialmente em dispositivos com áreas de visualização menores, mantendo o círculo e o grimório acessíveis.

6. Expansão do décimo selo secreto

Aprimorar a revelação de CHAOS, adicionando uma sequência visual mais elaborada e um efeito final que destaque a conclusão dos nove rituais anteriores.

Essas funcionalidades representam ideias para a evolução do projeto e poderão ser ajustadas conforme os testes e o desenvolvimento nas próximas semanas.
