Um sketch feito com ajuda do ChatGPT, com cores, posições e inclinações variáveis, seguindo dimensões da proporção áurea.

Autor: Diogo dos Santos Machado Vieira

Prompt usado: Crie um sketch estático em p5.js, sem animações, e apresente o resultado em um único código JavaScript que possa ser copiado e executado diretamente em um ambiente como o editor.p5js.org. O tamanho do canvas deve se ajustar ao espaço disponível na janela, utilizando windowWidth e windowHeight em vez de dimensões fixas.  O sketch também deve apresentar alguma variação a cada vez que for executado, para que o resultado não seja sempre exatamente o mesmo. Mesmo com essas variações, o desenho deve seguir uma lógica geométrica definida, considerando elementos como posição, tamanho, direção e inclinação das formas.

Para a parte visual, faça uma composição inspirada na razão áurea, usando suas formas e proporções como referência para criar o design.
