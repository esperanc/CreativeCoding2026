# Estrada Generativa

Este trabalho é uma evolução do sketch **Estrada em Perspectiva** entreque no artefato 1. Este trabalho é uma evolução do sketch **Estrada em Perspectiva** entreque no artefato 1. A ideia da arte é a mesma, no entanto dessa vez foram usadas outras primitivas, aumentando a complexidade das formas presentes na imagem gerada. Alem disso, dessa vez foram usadas formulas de randomização para gerar uma paisagem nova a cada execução.

O programa sorteia a paleta de cores, a posição do horizonte e do ponto de fuga, o formato das montanhas, a localização do sol ou da lua, as nuvens, as estrelas, as faixas da pista, as plantas e os postes. O desenho, portanto, segue regras de perspectiva, mas não produz sempre a mesma imagem.

O canvas é criado com `windowWidth` e `windowHeight`. Todas as posições e dimensões são calculadas a partir do espaço disponível, fazendo o desenho se adaptar a janelas de tamanhos e proporções diferentes. Quando a janela é redimensionada, a composição é recalculada.

Também é possível clicar na imagem para gerar uma nova variação.
