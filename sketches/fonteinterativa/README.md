## Autor: Nick Correa
Esse artefato apresenta uma simulação física de palavras de forma interativa. 
Para interagir, movimente o cursor sobre a palavra.

A fonte foi escolhida em homenagem ao mês de outubro.

OBS: Para palavras grandes (+5 caracteres) há problemas de performance devido à simulação física.
