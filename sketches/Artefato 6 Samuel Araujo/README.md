# Emergência

**Artefato 6 — "Emergência"** · Programação Criativa (Mestrado UFRJ) · Samuel Vitor



Na estrada, recebe uma ligação desesperadora. Você dirige de volta para casa a toda velocidade. O tempo é seu maior inimigo.

## Controles

- **Espaço** — acelerador (segure)
- **↑ / ↓** — trocar de marcha
- **Arrastar o mouse** — girar o motor livremente
