# Círculos em Órbita Espacial

**Círculos em Órbita Espacial** é uma composição generativa feita principalmente com a primitiva `circle()` do p5.js. A cada execução, o programa cria círculos de diferentes tamanhos, posições, cores e transparências. Alguns se sobrepõem, alguns recebem anéis e outros são preenchidos por pequenas bolinhas.

O desenho não utiliza estrada, paisagem ou ponto de fuga. Ele ocupa toda a janela como uma composição abstrata e se adapta ao espaço disponível usando `windowWidth`, `windowHeight`, `width` e `height`. Um clique gera uma nova versão.

**Autor:** Arthur Ramos

## Obras usadas como inspiração

### _Several Circles_ (1926), de Wassily Kandinsky

Link: [Guggenheim — Several Circles](https://www.guggenheim.org/artwork/1992)

A obra de Kandinsky usa círculos coloridos de tamanhos diferentes sobre um fundo escuro. Alguns círculos se sobrepõem e parecem flutuar no espaço. Meu sketch aproveita essa ideia de composição, mas as posições, cores e dimensões são escolhidas aleatoriamente pelo programa.

### _Dots Obsession_, de Yayoi Kusama

Links: [QAGOMA — Dots Obsession](https://play.qagoma.qld.gov.au/looknowseeforever/works/dots/) e [vídeo da Tate no YouTube](https://www.youtube.com/watch?v=rRZR3nsiIeA)

Kusama utiliza a repetição de bolinhas para cobrir objetos e ambientes. No sketch, essa referência aparece nos pequenos pontos espalhados pelo fundo e dentro de alguns círculos maiores. A repetição de uma forma muito simples cria uma imagem mais rica.

OBS: ambas as referencias foram achadas e escolhidas ultilizando IA generativa (chatGPT) para minha ideia das bolinhas

## Como executar

Abra `index.html` em um navegador com acesso à internet ou copie o conteúdo de `sketch.js` para o editor do p5.js.

## Interação

- **Clique do mouse:** gera uma nova composição.
- **Redimensionar a janela:** adapta o desenho ao novo tamanho disponível.
