Um sketch feito pelo ChatGPT usando apenas quads

Autor: João Pedro Moretti Fontes Ferreira

prompt usado: "Crie um sketch estático (sem animação) em p5.js. Apresente o resultado sob a forma de um único script em JavaScript a ser colado no editor.p5js.org.

O tema da arte deve ser inspirado no Fluminense Football Club, especialmente em suas cores tradicionais: verde, branco e grená. Não quero simplesmente reproduzir o escudo do clube; quero criar uma composição artística e abstrata que remeta ao Fluminense.

Regras obrigatórias:

A única primitiva geométrica de desenho permitida é quad().
Não use rect(), ellipse(), triangle(), line(), arc(), beginShape() ou outras primitivas de desenho.
É permitido usar comandos de estilização como fill(), stroke(), strokeWeight() etc.
O sketch deve ser completamente estático, sem animação.
Todo o desenho deve ser construído exclusivamente pela combinação de quadriláteros.
O código deve funcionar diretamente no editor.p5js.org.
Organize o código de forma simples e clara e documente-o com comentários para que possa ser explicado a uma plateia de iniciantes em programação.

Ideia visual:
Crie uma composição elegante formada por vários quadriláteros que lembrem faixas diagonais de uma camisa ou bandeira tricolor. Use predominantemente verde, branco e grená, alternando essas cores de maneira organizada. Os quadriláteros podem variar levemente de tamanho, posição e inclinação para criar uma composição dinâmica, mas devem manter uma aparência harmoniosa.

Quero que a arte tenha uma identidade visual que lembre o Fluminense sem precisar desenhar literalmente seu escudo, jogadores ou outros símbolos. Dê preferência a uma composição geométrica moderna e artística, com profundidade visual criada apenas pela sobreposição, disposição e cores dos quadriláteros.

Inclua também um fundo coerente com a composição.

No final, forneça apenas o código JavaScript completo, pronto para ser copiado para o editor.p5js.org."
