Follows the ideas in https://samuelbigos.github.io/posts/2dgi1-2d-global-illumination-in-godot.html about computing a global illumination in 2D using ray-marching and jump flooding.

# Usage
Hit space to change the visualization between Illumination / Voronoi Diagram / Distance field
