Sketch em p5.js v2 (via CDN jsDelivr) que carrega uma imagem de https://picsum.photos
e a reconstrói com pinceladas de partículas que seguem um campo de ruído (Perlin noise).
Clique no canvas para recomeçar a pintura.

O sketch não contém imagens nem a biblioteca p5.js.
