- Conceito

Memória Noturna é um artefato generativo inspirado em uma fotografia noturna em uma cidade. A cena é reinterpretada inteiramente com código, usando céu, montanhas, prédios e luzes como elementos visuais.

A proposta é representar uma memória que se transforma continuamente por meio do movimento das partículas e das luzes.

Artefato desenvolvido com auxílio de AI (ChatGPT).


- Imagem de referência

Referência utilizada: https://fastly.picsum.photos/id/43/1280/831.jpg?hmac=glK-rQ0ppFClW-lvjk9FqEWKog07XkOxJf6Xg_cU9LI

A imagem é utilizada apenas como referência visual e não é incorporada ao sketch.


- Interação

Mouse: movimenta as partículas.

R: recria a cena.

S: salva a imagem em PNG.
