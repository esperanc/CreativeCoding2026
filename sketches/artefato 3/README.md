# Cenário bucólico
## Descrição
Este projeto consiste em um sketch estático representando uma paisagem com um rio, jardins nas margens, flores, montanhas e um sol durante o pôr do sol.

O principal objetivo do sketch é aplicar conceitos de **layout geométrico**, utilizando relações entre posições, dimensões e proporções para determinar onde e como os elementos da cena são desenhados.

O cenário não utiliza coordenadas fixas para definir todo o desenho. As posições e dimensões são calculadas pelo programa de acordo com o tamanho disponível para o canvas, permitindo que a composição se adapte a diferentes tamanhos de tela.
