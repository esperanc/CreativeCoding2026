Primeiro sketch para o projeto final que tem como objetivo criar animações para facilitar a compreensão da norma técnica ABNT NBR 9050/2020. Um cenário foi modelado no software ArchiCAD e posteriormente, com o uso da IA Claude realizou-se a animação do modelo arquitetônico. Como produto final pretende-se realizar a animação de elementos gráficos do tópico 4.2 - Pessoas em cadeira de rodas (P.C.R.) da norma supracitada.
