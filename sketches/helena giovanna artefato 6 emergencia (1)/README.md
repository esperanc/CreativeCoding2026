Uma simulação interativa de inteligência de enxame desenvolvida em p5.js, utilizando o clássico algoritmo de Boids de Craig Reynolds.  Feito pelo Google Gemini.

O projeto demonstra como comportamentos de grupo orgânicos e complexos (semelhantes a cardumes de peixes ou bandos de aves) podem emergir do alinhamento de três regras locais simples:

- Separação: Evita aglomeração e colisão com vizinhos próximos.
- Alinhamento: Harmoniza a direção e velocidade com o grupo local.
- Coesão: Mantém o grupo unido ao atrair o agente para a posição média dos vizinhos.

Interatividade
- Clique / Arraste (Mouse): Cria um ponto de atração para o enxame.
- Teclado (Qualquer tecla): Alterna o ponteiro para o modo Repulsão/Predador, dispersando o grupo.

O projeto pode usar agentes, partículas ou outros elementos que interajam entre si, gerando padrões ou comportamentos inesperados. Use p5.js e inclua alguma forma de interação com o usuário."
