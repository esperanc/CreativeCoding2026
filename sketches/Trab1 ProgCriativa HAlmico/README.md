Um sketch feito pelo Claude usando apenas quads.

Autor: Henrique Almico Dias da Silva

Prompt usado: Crie um sketch estático (sem animação) em p5.js, em um único script para colar no editor.p5js.org. Use apenas o comando quad como primitiva de desenho (stroke, fill, strokeWeight e transparência são permitidos para estilização). A composição deve ter inspiração neoconcreta: fundo escuro sofisticado, paleta pastel com uma única cor vibrante de destaque, formas dispostas em diagonal (evitando grades retas), proporções variadas (de finas e alongadas a robustas) e sobreposições com transparência para gerar novos tons nas interseções. O código deve ser bem documentado em português, explicando a lógica matemática por trás da distorção dos vértices e as escolhas de composição, de forma acessível a iniciantes.
