Imagem feita com auxilio de IA Claude com o seguinte prompt: 
Construa o código para gerar uma imagem em p5.js2, onde as cores da foto se unem nos cantos da tela, como se agrupassem os pixels que estavam espalhados. Coloque uma tonalidade de cor em cada canto (4 cores) e uma no centro. As uniões entre essas cores são as variações de cor entre elas, formando um espectro gradiente com os pixels por aproximação, que vai de um canto a outro. Carregue a imagem aleatória do https://picsum.photos/ tornando cada acesso uma experiência nova.
