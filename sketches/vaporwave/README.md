Um Sketch feito pelo ChatGPT usando apenas Quads.
Autor: Ysabelle Estevão de Oliveira
Prompot usado: Crie um sketch estático (sem animação) em p5.js. Apresente o  resultado sob a forma de um único script em javascript a ser colado num  ambiente de desenvolvimento como o editor.p5js.org. O sketch deve usar  como primitiva de desenho apenas o comando quad. É permitido usar  comandos de estilização como stroke, fill, strokeWeight, etc. O programa  fonte deve ser documentado para ser explicado para uma plateia de  iniciantes em programação de computadores.  Gostaria que fosse criado com o codigo uma arte estilo vaporwave, com bastante neon e elementos de programas antigos de computador como por exemplo o windows 98.
