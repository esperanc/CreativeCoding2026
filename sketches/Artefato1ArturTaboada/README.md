# Composição Geométrica com Quadriláteros

Este sketch cria uma composição abstrata utilizando apenas a primitiva `quad()` do p5.js. O objetivo foi explorar princípios de composição artística, como repetição, variação, hierarquia e contraste, mantendo um estilo geométrico minimalista e organizado.

## Como o sketch funciona
- O código percorre uma estrutura lógica para desenhar formas, variando sua posição e tamanho.
- Utiliza-se uma paleta de cores definida para garantir a harmonia visual.
- A função `linhaquad()` automatiza o preenchimento de cada "linha" de elementos com uma cor diferente da paleta.
- Não se utiliza bordas (`noStroke()`) para obter um visual mais limpo.

2. Copie todo o conteúdo do arquivo `sketch.js` deste zip e cole na área de edição de código do site.
3. O resultado será renderizado na tela de visualização após o botão "Run" ser clicado.
