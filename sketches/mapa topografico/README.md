Autora: Rafaella Lenzi Romano

Uma foto de montanha redesenhada como mapa topográfico. O brilho de cada pixel é tratado como altitude, e o sketch traça as curvas de nível que essa "altitude" forma, com a cor original de cada lugar da imagem.
 
O resultado é uma montanha desenhada como mapa de montanha: o céu branco vira papel em branco, e as linhas contornam o musgo, as faixas de neve e o chão de cascalho.
