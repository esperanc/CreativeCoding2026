Este sketch representa uma espiral de estrelas cuja posição é determinada pela equação da **Espiral de Arquimedes**:

r = a * θ

* **r (raio):** distância do ponto até o centro.
* **θ (theta/ângulo):** rotação em graus.
* **a (constante):** espaçamento entre as voltas.

Como as telas usam coordenadas cartesianas (x, y), convertemos polar para cartesiano usando trigonometria básica:

* x = r * cos(θ)
* y = r * sin(θ)
