### Autor: Nick Correa

Representação de possíveis movimentos de um cavalo num tabuleiro de xadrez. ChatGPT foi usado para o código iterativo de pintar o tabuleiro. O cavalo foi feito manualmente calculando coordenadas no figma a partir de uma imagem de exemplo também gerada por IA.

### Prompts usados:

"escreva um código usando a primitiva quad para p5 front para desenhar um tabuleiro de xadrez"

"quero que 
desenhe um 'cavalo' usando apenas a primitiva quad em uma das casas do tabuleiro
As casas que o cavalo poderia se mover devem estar em verde"
