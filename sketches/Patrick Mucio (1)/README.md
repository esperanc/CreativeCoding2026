# Artefato da Semana 

**Nome:** Patrick Mucio 

# Órbita Viva

A proposta do projeto é criar um universo visual formado por partículas, rastros, forças de atração e repulsão. A composição nunca fica exatamente igual: o movimento das partículas e a interação do usuário alteram a imagem continuamente.


## Interações

- **Mover o mouse:** interfere no campo gravitacional.
- **Clique:** cria um núcleo de atração.
- **Shift + clique:** cria um núcleo de repulsão.
- **1:** modo Órbita.
- **2:** modo Tempestade.
- **3:** modo Vórtice.
- **Espaço:** cria uma explosão.
- **C:** limpa/reinicia a composição.
- **P:** pausa ou continua.
- **H:** mostra ou oculta as instruções.
- **S:** salva uma imagem da composição.
