Um sketch usando coordenadas polares e transformações afim para desenhar uma mandala.

Autor: Natan Azevedo Gomes

Prompt: Crie um sketch estático (sem animação) em p5.js. Apresente o resultado sob a forma de um único script em javascript a ser colado num ambiente de desenvolvimento como o editor.p5js.org. O sketch pode usar as primitivas background, point, line, rect, ellipse, triangle, circle, square, quad, arc ou bezier. É permitido usar comandos de estilização como stroke, fill, strokeWeight, etc. O programa fonte deve ser documentado para ser explicado para uma plateia de iniciantes em programação de computadores. O sketch deve usar coordenadas polares, podendo usar as funções sin e cos, e transformadas afins como translate, rotate, scale e shear (usando push e pop) para desenhar uma mandala. Não preencha os elementos da mandala com cores, deixe ela apenas com os contornos. Utilize uma paleta de cores variada e intensa, e faça um fundo preto. O sketch deve se adequar ao tamanho da janela, usando windowWidth e windowHeight. Tome cuidado para que a mandala não fique "cortada" pela janela.
