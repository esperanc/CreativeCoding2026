## keyboard commands
d : toggles debug mode
>, <: Zooms in / out
+, - : increases / decreases color luminosity
p : cycles palette
3-9 : set symmetry 
r : toggles reflection symmetry
q : toggles square mode
a : toggles auto demo
s : save image
