# Artefato da Semana 6 — Emergência

**Nome:** Patrick Mucio 

## Cardume Emergente

Cada peixe funciona de maneira independente e segue apenas três regras simples:

1. **Separação:** evita ficar muito próximo dos outros peixes.
2. **Alinhamento:** tenta nadar na mesma direção dos peixes próximos.
3. **Coesão:** tenta permanecer próximo do grupo.

Não existe uma regra dizendo diretamente aos peixes para formarem um cardume. A organização coletiva surge naturalmente da interação entre essas regras simples.

## Interação

- Mova o mouse pela tela para afastar os peixes próximos.
- Clique em qualquer ponto para adicionar cinco novos peixes.
- Depois de serem dispersados, os peixes começam a se reorganizar novamente.

## Como executar

Abra o arquivo `index.html` em um navegador com acesso à internet. O projeto utiliza a biblioteca p5.js por CDN.
