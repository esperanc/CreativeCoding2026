Para este sketch sobre layout, procurei inspiração em duas obras muito semelhantes. A primeira é a capa do livro Grid Systems, considerado o guia essencial do design de layouts. A segunda vem de uma imagem num artigo que li recentemente sobre o estudo de formas primárias feito por alunos na Bauhaus.  

Pensei em combinar a identidade da capa com a ideia de subdivisão dos quadrados de uma das imagens do artigo para criar um gerador de layouts infinito.  

Inspirado pelo seminário da semana anterior, decidi realizar este sketch apenas com o Antigravity 2.0, sem alterar o código manualmente, assumindo o papel de orientador da IA. O resultado revelou-se muito PIOR do que se tivesse usado a IA apenas como uma ferramenta de apoio e pesquisa, como nos sketches anteriores.
