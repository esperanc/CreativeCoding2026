# Andarilho

> Nome: Laura Daflon dos Santoa Santana Meira
>
> DRE: 120053993

Um andarilho, que anda, anda, mas nunca chega a nenhum lugar. A luz é azulada tal qual quando andamos sob a luz do céu noturno. Ele anda pela areia. A ideia é uma pessoa perdida no deserto, andando sem achar nada.

Ele é moldado por cubos, alguns arredondados, outros não.
