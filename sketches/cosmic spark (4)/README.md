## Descrição

Este sketch cria um padrão geométrico formado por faixas coloridas que se repetem pela tela. As faixas possuem diferentes larguras e alternam sua posição entre as linhas.

O desenho utiliza quadriláteros (`quad()`) sem contornos, permitindo que as cores fiquem diretamente próximas umas das outras. O contraste entre o preto, cinza e as cores saturadas cria um efeito visual semelhante ao da obra utilizada como inspiração.

## Inspiração

Este trabalho foi inspirado pela seguinte imagem:

https://pin.it/6dGcmdllk

A principal inspiração foi o uso de faixas verticais coloridas, a repetição do padrão e a ausência de bordas entre as formas. A disposição, as proporções e as cores foram adaptadas para criar uma composição própria em p5.js.
