Boa noite, faça mais um sketch, agora com animação, ainda para p5.js. Apresente o resultado sob forma de um único em javascript a ser colado num ambiente de desenvolvimento como o editor.p5js.org. Inspirado nessa imagem, faça as folhas com formas geométricas. Elas devem se mover conforme o movimento do mouse, como se a pessoa pudesse mexer nas plantas. O tamanho das linhas deve variar randomicamente, e mudar como arte generativa.

Fiz mudanças nos tamanhos e quantidades para preencher mais o desenho. 

Depois de revisar os trabalhos anteriores percebi que uma forma de criar algo novo é se inspirar em na natureza. Ao invés de descrever apenas o que eu queria, também enviei uma imagem de referência. Deu super certo!
