# Jardim em Movimento

**Jardim em Movimento** é um artefato de arte generativa tridimensional desenvolvido com p5.js 2 e WebGL.

A obra apresenta um jardim fantástico construído por meio de regras algorítmicas. Flores abstratas, pétalas, caules curvos e esferas coloridas formam uma escultura cinética na qual os elementos giram e oscilam continuamente.

A composição combina formas geométricas simples para sugerir estruturas vegetais imaginárias, explorando cores vibrantes, profundidade, iluminação e movimento. Em vez de reproduzir fielmente um jardim natural, o projeto propõe uma interpretação visual na qual plantas e objetos geométricos se misturam.

A estrutura é gerada por código e pode ser reorganizada interativamente, produzindo novas composições a cada regeneração.

## Controles

- **Arrastar o mouse:** observar o jardim de diferentes ângulos.
- **Rolar o mouse:** aproximar ou afastar a câmera.
- **Clicar:** gerar uma nova composição.
- **S:** salvar uma imagem do artefato.

## Tecnologias

- HTML5
- JavaScript
- p5.js 2.0.4
- WebGL
