Um quadro onde cada agente caminha para frente e deixa um rastro químico (um pixel que brilha e evapora com o tempo). A cada passo, o agente aciona três "sensores" à sua frente (esquerda, centro e direita) para ler os rastros no chão. Ele sempre vira para a direção onde o brilho do rastro é mais forte.
Esse comportamento cria a emergência, feito com auxílio do ChatGPT.
