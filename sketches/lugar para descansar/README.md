Artefato 9 – Sofá 3D de Três Lugares

Este artefato consiste na criação de um sofá tridimensional de três lugares, desenvolvido com a biblioteca p5.js utilizando o modo WebGL. O projeto utiliza exclusivamente primitivas geométricas 3D, como elipsoides, esferas, cilindros, caixas e toros, para construir as diferentes partes do móvel.

O sofá apresenta um design aconchegante e confortável, com assentos acolchoados, encosto macio, braços arredondados, pés de madeira curtos e almofadas decorativas em diferentes cores e formatos. A iluminação e a combinação de cores suaves contribuem para uma aparência agradável e realista.

Além da modelagem tridimensional, o artefato utiliza transformações geométricas, como translação e rotação, para posicionar e organizar os elementos. A função orbitControl() permite explorar o modelo de diferentes ângulos por meio do mouse.

O objetivo do projeto é demonstrar a aplicação de primitivas geométricas, iluminação, cores e transformações no desenvolvimento de objetos tridimensionais interativos, explorando os recursos de computação gráfica disponíveis no p5.js.
