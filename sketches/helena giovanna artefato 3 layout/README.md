Um sketch feito pelo ChatGPT com uma composição geométrica estática baseada em posição, direção e tamanho.

Autora: Helena Giovanna

Prompt usado: "Crie um sketch estático em p5.js com uma composição de formas geométricas futuristas organizadas ao redor de um ponto central.

Quero que as formas sejam posicionadas seguindo uma regra geométrica, usando ângulos e distâncias em relação ao centro da tela. Use `sin()` e `cos()` para calcular as posições e `rotate()` para fazer com que as formas tenham direções diferentes de acordo com sua posição.

O tamanho das formas também deve variar de maneira organizada, por exemplo aumentando ou diminuindo conforme a distância do centro. Pode usar `map()` para fazer essa variação.

O canvas deve se adaptar ao tamanho da janela usando `windowWidth` e `windowHeight`, e o desenho também deve se ajustar usando `width` e `height` como referência.

Pode usar diferentes primitivas do p5.js e cores para deixar o resultado mais interessante, mas tente manter o código relativamente simples e com comentários explicando as partes principais.

O resultado deve ser estático, sem animação, e usar `noLoop()`.""
