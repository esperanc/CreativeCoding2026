# Tempestade Tipográfica

Artefato desenvolvido para a Semana 7, cujo tema é Tipografia.

A proposta é representar uma tempestade utilizando a própria tipografia
como elemento visual principal.

Palavras como "CAOS", "ORDEM", "TEMPO", "VOZ", "FORMA" e "IDEIA"
se comportam como gotas de chuva e são movimentadas pelo vento.

A nuvem também é construída utilizando palavras, enquanto correntes de
vento e relâmpagos são representados através de caracteres tipográficos.

## Interações

- Movimento horizontal do mouse: altera a direção e intensidade do vento.
- Aproximar o mouse das palavras: provoca uma corrente de ar que as afasta.
- Clique do mouse: cria um relâmpago tipográfico e espalha as palavras.
- Barra de espaço: reorganiza as palavras e gera uma nova tempestade.


## Uso de Inteligência Artificial

O desenvolvimento deste artefato contou com auxílio de inteligência
artificial ChatGPT para geração e adaptação do código.

Nenhum arquivo de fonte externo é utilizado pelo projeto.
