# Desenho com Quadriláteros

**Nome:** Laura Daflon dos Santos Santana Meira
**DRE:** 120053993

## Descrição

Este sketch foi desenvolvido em p5.js como parte da atividade **"Desenho com Quadriláteros"**. A composição utiliza apenas o `quad()` para desenhar as formas visuais e a ideia foi criar um padrão geométrico formado por quadriláteros coloridos organizados em faixas diagonais. As core foram escolhidas a partir de preferência pessoal.

## Construção do desenho

O desenho é construído a partir de um nested loop, onde o loop interno faz a repetição dos quadrados em uma linha diagonal, enquanto o loop externo desloca essa linha em outra linha diagonal. O objetivo era preencher todo espaço disponível.

## Recursos utilizados

- p5.js
- `quad()`
- `fill()` 
- `noStroke()` para tirar a borda
