Um sketch feito pelo ChatGPT usando apenas quads.

Autora: Helena Giovanna

Prompt usado: "Crie um sketch estático, sem animação, em p5.js, apresentando o resultado como um único script JavaScript que possa ser colado e executado diretamente no editor.p5js.org.

O tema visual do sketch será uma cidade futurista durante a noite, vista de frente, com diferentes prédios, janelas iluminadas, ruas e reflexos.

Regras obrigatórias

* Utilize como única primitiva geométrica de desenho o comando `quad()` do p5.js.
* Não utilize `rect()`, `ellipse()`, `circle()`, `triangle()`, `line()`, `arc()` ou outras primitivas geométricas.
* É permitido utilizar comandos de estilização, como `fill()`, `stroke()`, `noStroke()`, `strokeWeight()`, entre outros.
* O sketch deve ser completamente estático, portanto não deve possuir animações ou elementos que mudem com o tempo.
* Utilize um canvas de 800 × 600 pixels.

Composição visual

Construa a imagem utilizando diferentes quadriláteros:

* O fundo deve representar um céu noturno.
* Crie vários prédios com alturas e larguras diferentes.
* Alguns prédios podem apresentar pequenas inclinações ou perspectivas, aproveitando os quatro pontos independentes do `quad()`.
* As janelas devem ser pequenos quadriláteros organizados em padrões, com algumas iluminadas e outras apagadas.
* Na parte inferior da imagem, crie uma rua ou superfície que apresente sensação de perspectiva.
* Utilize quadriláteros alongados para criar reflexos das luzes dos prédios sobre a rua.
* Acrescente alguns elementos abstratos no céu construídos também exclusivamente com `quad()`.
* Procure criar sensação de profundidade utilizando sobreposição, diferenças de tamanho e variações de tonalidade.

Organização do código

O código deve ser simples e adequado para estudantes iniciantes em programação.

Comente o programa em português explicando:

1. a criação do canvas;
2. a definição das cores;
3. como funciona o comando `quad()`;
4. quais grupos de quadriláteros formam cada elemento da imagem;
5. como as coordenadas dos quatro vértices determinam o formato de cada quadrilátero.

Evite estruturas excessivamente complexas. Dê preferência a código claro e fácil de modificar posteriormente.

Ao final, entregue somente o código JavaScript completo, pronto para ser copiado para o editor do p5.js."
