Sketch feito pelo Chat GPT usando apenas quads.

Autor: Manoel V C Carvalho

Prompt usado: Crie um sketch estático (sem animação) em p5.js. Apresente o resultado sob a forma de um único script em javascript a ser colado num ambiente de desenvolvimento como o editor.p5js.org. O sketch deve usar como primitiva de desenho apenas o comando quad. O sketch dever conter tonalidades de rosa, roxo, fúcsia e lilás, criando um skyline (Panorama Urbano) usando como base a cidade de Saffron da franquia de jogos Pokémon, usar prioritariamente o modelo da cidade presente no jogo Let´s Go Pikachu. É permitido usar comandos de estilização como stroke, fill, strokeWeight, etc. O programa fonte deve ser documentado para ser explicado para uma plateia de iniciantes em programação de computadores.
