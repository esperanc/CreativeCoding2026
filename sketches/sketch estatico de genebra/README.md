Um sketch feito com Claude Ai usando apenas quads. 

Autora: Rafaella Lenzi Romano

Prompt usado: Crie um sketch estático (sem animação) em p5.js que se assemelhe à paisagem do lago de Genebra com o jet d'eau e as montanhas. Apresente o resultado sob a forma de um único script em javascript a ser colado num ambiente de desenvolvimento como o editor.p5js.org. O sketch deve usar como primitiva de desenho apenas o comando quad. É permitido usar comandos de estilização como stroke, fill, strokeWeight, etc. O programa fonte deve ser documentado para ser explicado para uma plateia de iniciantes em programação de computadores. 

Link da imagem enviada: https://share.google/E8wO1ASHej2dTpFOZ 

Além dos prompts iniciais, foram feitas iterações para adicionar telhados aos prédios e para melhorar o aspecto da margem do lago, do arco-íris e do barco de passeio. Ajustes de escala, cor, posição e etc foram feitos manualmente.
