Creates symmetric flow field patterns using wallpaper groups

## Keyboard commands:
f : decrease fade factor (more opaque)
F : increase fade factor (more transparent)
+ : zoom in
- : zoom out
G,g: New wallpaper group for the same field
> :  increases tile size
< :  decreases tile size
c,C: color scheme cycle
any other key: randomize
