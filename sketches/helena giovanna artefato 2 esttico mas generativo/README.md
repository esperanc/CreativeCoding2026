Um sketch feito pelo ChatGPT - artefato estático mas generativo

Autora: Helena Giovanna

Prompt usado: "Crie um sketch em p5.js de uma **cidade futurista à noite**.
Quero que o desenho seja **estático**, sem nenhuma animação, mas que seja diferente cada vez que o código for executado. Para isso, use `random()` para variar coisas como altura e largura dos prédios, posição das estrelas, janelas acesas e cores das luzes.
O canvas deve se adaptar ao tamanho da janela usando `createCanvas(windowWidth, windowHeight)`, e os elementos do desenho devem usar `width` e `height` como referência para também se adaptarem ao tamanho disponível.
Pode usar as primitivas do p5.js que forem necessárias, como `rect()`, `circle()`, `triangle()`, `quad()` e `line()`.
A cidade deve ter prédios, janelas, céu com estrelas, uma rua e alguns elementos que deem uma aparência futurista. Use `noLoop()` para manter o resultado estático depois que ele for gerado.
Tente manter o código relativamente simples, sem usar recursos muito avançados, e coloque comentários explicando as partes mais importantes."
