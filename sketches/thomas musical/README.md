Dessa vez eu quis brincar com meu nome. Escrevi Thomas só com notas musicais. A ideia é que o nome pareça uma partitura, como se desse para tocar ele.

O truque para montar o nome é mais simples do que parece. O sketch escreve "Thomas" escondido, fora da tela, e depois vai "carimbando" uma nota em cada pedacinho que cai dentro das letras. Cada nota tem uma figura, um tamanho e uma inclinação diferentes, e todas balançam de leve o tempo todo. Por isso o nome parece estar vivo, e não impresso.

A parte de que eu mais gosto é a interação. Quando você passa o mouse por cima do nome, as notas perto do cursor crescem, ficam vermelhas e se endireitam. Quando o mouse vai embora, elas voltam devagarinho ao normal.
