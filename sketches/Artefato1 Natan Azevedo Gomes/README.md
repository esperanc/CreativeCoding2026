Um sketch feito pelo Gemini apenas com quads.

Autor: Natan Azevedo Gomes

Prompt: Crie um sketch estático (sem animação) em p5.js. Apresente o resultado sob a forma de um único script em javascript a ser colado num ambiente de desenvolvimento como o editor.p5js.org. O sketch deve usar como primitiva de desenho apenas o comando quad. É permitido usar comandos de estilização como stroke, fill, strokeWeight, etc. O programa fonte deve ser documentado para ser explicado para uma plateia de iniciantes em programação de computadores. Pode criar quadriláteros sobrepostos e dispersos, de tamanhos e orientações diferentes. Utilize uma paleta de cores pastel com uma saturação baixa.
