# Nostradamus

> Nome: Laura Daflon dos Santos Santana Meira
>
> DRE: 120053993

Michel de Nostradame nasceu em Saint-Rémy-de-Provence, no sul da França, em dezembro de 1503. É conhecido
como um vidente famoso com profecias que nos permeiam até hoje. Esse trabalho é uma forma de remeter a 
ideia de projeção do futuro, mas contemplando algo da modernidade: a computação.

A proposta desse trabalho é falar sobre o meio ambiente e dados, mais especificamente
como o uso de dados pode nos auxiliar nesse processo de identificar que ações hoje em dia
podem acabar piorando o futuro do planeta.

A ideia é usar essa estética de computador antigo, para apresentar um modelo 3D de um mundo que se
altera conforme compostos são alterados. Então, o que aconteceria se aumentamos a quantidade de PFAs no mundo?
Usamos dados para prever de uma forma lúdica e interativa.

Na primeira entrega, tem-se a base do mundo e a interface principal feitas.
