title: Gatinhos pulando nas caixas

Eu gosto muito de gatos, então tive a ideia de fazer algo com eles. Aqui, a cena começa com um gato sozinho e é possível usar o mouse para criar uma caixa. O gato, então, pula para cima da caixa. A cada 5 caixas criadas, um gato novo aparece, e com vários, o mais próximo da caixa criada pula para ela. Os gatinhos têm uma animação para sentar caso fiquem 2 segundos sem pular, e, depois de alguns segundos sentados (entre 7 e 14), eles pulam para outra caixa aleatoriamente.

A própria caixa de papelão é um modelo importado: um arquivo OBJ escrito à mão dentro do código. Também dá para arrastar um arquivo .obj ou .stl para a janela: o objeto aparece onde foi solto e vira mais um lugar para os gatos.
