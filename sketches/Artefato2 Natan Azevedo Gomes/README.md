Paisagem gerada com primitivas, de forma generativa. 

Nome: Natan Azevedo Gomes

Prompt: Crie um sketch estático (sem animação) em p5.js. Apresente o resultado sob a forma de um único script em javascript a ser colado num ambiente de desenvolvimento como o editor.p5js.org. O sketch deve usar apenas, mas não necessariamente, as primitivas background, point, line, rect, ellipse, triangle, circle, square, quad, arc ou bezier. É permitido usar comandos de estilização como stroke, fill, strokeWeight, etc. O programa fonte deve ser documentado para ser explicado para uma plateia de iniciantes em programação de computadores. Os elementos podem ter tamanhos e orientações diferentes, além de poderem estar sobrepostos, mas eu queria que eles formassem uma paisagem. Utilize uma paleta de cores pastel com uma saturação baixa. O sketch deve se adequar ao tamanho da janela, usando windowWidth e windowHeight, e usar random para gerar imagens diferentes a cada execução
