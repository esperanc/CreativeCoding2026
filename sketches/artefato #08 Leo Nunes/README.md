Esteganografia é a prática de "esconder mensagens dentro de outras mensagens" para que as primeiras não sejam encontradas e criptografia é a prática de "emparalhar mensagens" para que estas fiquem ilegíveis.

Este programa tem 2 modos de uso:

* CODE: uma mensagem é criptografada com uma chave textual, escondida(esteganografada) dentro de uma imagem aleatória(sem alterar visivelmente esta, pois ela é mudada nos bits menos significativos de seus pixels) para então o usuário baixar a imagem portadora.

* DECODE: o programa recebe uma imagem portadora e uma chave textual para decodificar a mensagem escondida nela, se houver uma e a chave estiver correta.

A ideia deste artefato é mostrar que a informação contida numa imagem não somente é aquilo que se vê, os bits podem guardar segredos.
