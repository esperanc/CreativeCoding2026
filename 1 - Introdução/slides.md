# O que é programação criativa?
Em essência é usar programação de computadores para explorar ideias.

Num contexto mais informal, é o uso de código como ferramenta criativa.

Neste curso vamos nos concentrar em uso de código para gerar imagens e animações.
---
# História

A programação criativa tem raízes que remontam aos primórdios da computação.

Desde cedo, artistas e cientistas usaram o computador não apenas para calcular, mas também para _criar_.

Vamos ver alguns artistas mais marcantes. Muito deste material foi pesquisado no Digital Art Museum (https://dam.org/museum/)

# Processing e P5.js

_Processing_ (veja https://processing.org) foi um marco da programação criativa.
 - Oferece um IDE simples
 - API para desenho 2D e 3D
 
Dentre os muitos projetos que se inspiraram no Processing, o P5.js (https://p5js.org) é o mais popular hoje em dia
 - Baseado em Javascript 
 - Mantém a API do Processing com adaptações
 - Funciona no navegador (sem instalação)

# O ambiente p5Front 

Diferentemente dos demais editores online, é estritamente _local_
- Também online, mas todo o processamento é no _front end_
- Todos os arquivos ficam na sua máquina 
- Não requer criar conta num servidor remoto
- Acesse em https://esperanc.github.io/p5front/
- Projeto hospedado em https://github.com/esperanc/p5front

# O uso de IA

Bom para:
- Ajudar a escrever código complexo
- Sugerir maneiras de implementar uma ideia 

Pode ser bom para
- Descobrir erros de codificação

Ruim para:
- Sugerir ideias originais
---
# Maneiras de usar IA

Chatbots (ChatGPT, Claude, Gemini)
- Cria código a partir de uma descrição
- Pode mostrar o código já funcionando
- Pode inibir a experimentação 

Agentic AI (Antigravity IDE, Cursor, VSCode+Copilot)
- O agente de IA atua dentro do editor
- Pode analisar o código existente
- Pode sugerir modificações no código existente
- Requer conhecimento de programação e das tecnologias utilizadas
- Mantém o usuário no controle do processo
